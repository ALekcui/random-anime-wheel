# 🎡 Random Anime Wheel (Колесо Фортуны)

**Удобное десктопное приложение на Python для случайного выбора аниме из вашего собственного списка.** Не можете решить, что посмотреть вечером? Просто добавьте варианты и доверьтесь колесу фортуны!

---

## ✨ Особенности

* **Динамическая генерация:** Колесо автоматически перестраивается, разбивается на сектора и окрашивается в случайные цвета в зависимости от количества элементов.
* **Удобный ввод данных:** Вводите названия вручную прямо в текстовое поле приложения (каждое аниме с новой строки) или загружайте готовые списки.
* **Импорт файлов:** Поддержка быстрой загрузки списков из файлов `.txt` (Также в будующем планируется добавить поддержку json файлов содержащих в себе экспортированные списки из shikimori)
* **Мгновенный переход к просмотру:** После остановки колеса активируется кнопка, которая автоматически открывает страницу с результатами поиска выбранного аниме в браузере.

---

## 🛠 Стек технологий

* **Язык программирования:** Python 3
* **Библиотека GUI:** Tkinter (встроенная)
* **Работа с изображениями:** Pillow (PIL)

---

## 🚀 Установка и запуск

### Прежде чем начать

Для работы приложения необходима библиотека `Pillow` для корректного отображения графических элементов интерфейса (иконки импорта файлов).

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/ALekcui/random-anime-wheel
   cd random-anime-wheel
   ```

2. **Установите зависимости:**

   ```bash
   pip install Pillow
   ```

3. **Запустите приложение:**

   ```bash
   python wheel-of-anime.py
   ```

---

## 📖 Как использовать

1. После запуска откроется окно с интерактивным колесом слева и панелью управления справа.
2. **Добавьте аниме в список:**
   * Введите названия вручную в текстовое поле (одно название — одна строка).
   * **ИЛИ** нажмите на иконку папки в правом нижнем углу, чтобы импортировать готовый список из файла `.txt`
3. Нажмите кнопку **"Сгенерировать колесо"**, чтобы обновить сектора на основе вашего списка.
4. Кликните по **зеленой кнопке в центре колеса**, чтобы запустить вращение.
5. Дождитесь остановки. Нажмите появившуюся кнопку **"Перейти на страницу аниме"**, чтобы открыть поиск на YummyAnime.
